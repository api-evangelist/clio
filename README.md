# Clio (clio)

Clio is a cloud-based legal practice management platform used by law firms for matter management, contacts, calendaring, time and billing, trust accounting, document management, tasks, and communications. The Clio Manage API is a REST/JSON API at `app.clio.com/api/v4` that uses OAuth 2.0 for authentication, with regional endpoints for the U.S., Canada, EU/UK, and Australia.
